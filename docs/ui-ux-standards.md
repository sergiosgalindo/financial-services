# UI/UX Standards

- **Framework:** Bootstrap 5.3 with responsive two-column layout.
- **Left Column:** Interactive Fintech Assistant chat console with quick-action prompts for CU-01 (Loan Simulation), CU-02 (Identity & Contract Validation), CU-03 (Monthly Cut & Unrecognized Charge Dispute), CU-04 (Payment Reconciliation), and Legal RAG queries (CAT, Moratory Interest, MSI).
- **Right Column:** Live Fintech Core Inspector displaying active database customers, credit accounts, interactive Loan Simulator widget, and real-time RAG/Function Calling execution trace.
- **Accessibility:** Semantic HTML5 landmarks, ARIA live regions for streaming/asynchronous messages, high-contrast financial status badges, and keyboard-accessible controls.
